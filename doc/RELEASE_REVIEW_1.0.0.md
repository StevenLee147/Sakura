## 2. 自动化压测与多分辨率验收

- **极限边界与压力单测 (`tests/test_v1_stress.cpp`)**：Windows MSVC x64（Debug + Release）与 Ubuntu Linux Ninja (`ci-linux`) 全量通过；覆盖空谱面防误判、`1660` 音符高密度混合 v3 谱面满分确定性、畸形 UTF-8 与截断 JSON 拦截、路径穿越防御、损坏 SQLite 数据库自动备份 `.corrupt.bak` 并重建、缺失音画视频优雅回退。
- **实机 GPU 流程巡检 (`--smoke-test --verify-play`)**：30 个实机阶段全绿通过，覆盖首次启动引导、曲库筛选、六页设置、六课教程、统计、工房试玩、新建中文谱面、校准、正式演奏与 Replay v2 逐帧重放、全屏深度报告以及《樱落呼吸》MP4 硬解舞台 + `F3` 实时诊断面板。
- **存档与格式兼容**：100% 向后兼容 Chart v1 / v2 / v3、Replay v1 / v2 与历史 SQLite 存档。
