# Sakura · 樱 玩家指南

## 第一首歌

第一次打开游戏时，建议完成 Tap、Hold、Circle、Slider 和混合操作五课教程。教程随时可以从主菜单重新进入，也会读取你设置的四轨键位。

打开「开始旅程」，选择 First Steps 或 Spring Breeze / Normal。左右方向键选择难度，上下方向键选择曲目，Enter 开始。开局有三秒准备时间。

| 音符 | 操作 |
|---|---|
| Tap | 音符到达左侧判定线时按对应轨道键，默认 A / S / D / F |
| Hold | 准时按下并保持到尾部；头部、尾部分别计分 |
| Circle | 右侧接近圈收拢时，用鼠标左键点击圆心 |
| Slider | 点击头部并保持左键，沿路径移动，按节奏经过节点 |

音乐、两侧音符使用同一歌曲时钟。鼠标命中范围会随操作区宽高比调整，不需要因窗口大小改变点击习惯。

Esc 暂停，R 重新开始当前曲目，F11 切换全屏。切换到其他窗口时自动暂停；继续时重新倒计时，长按中的音符提供短暂的恢复容错。

## 曲库和练习

搜索框支持曲名、作者、标签，Ctrl+F 聚焦搜索。可按曲名、BPM 或难度排序，使用收藏筛选。切换曲目时会记住所选难度，超过四个难度时可翻页。F5 刷新曲库。

| 模式 | 用途 | 正式记录 |
|---|---|---|
| 正式演奏 | 原速完成整首曲目 | 保存成绩、统计、成就与回放 |
| 自由练习 | 选择起止区间，0.5–2.0 倍速，可循环 | 不写入正式成绩 |
| 自动演示 | 观察两侧音符与节奏 | 不写入正式成绩 |
| 回放 | 重现已记录的输入 | 不再次增加成绩或游玩次数 |

练习仅计入整个音符都落在区间内的判定。跨越起止边界的 Hold / Slider 不参与该段计分。变速通过播放速率实现，会同时改变音高。

「播放最近回放」需要当前曲目、难度已有回放。修改音符、时间点、滚速点或谱面偏移后，旧回放会提示不匹配，避免把旧输入套到新谱面上。回放文件扩展名为 `.skr`，本版格式为 JSON v1。

## 成绩与偏差

满分为 **1,000,000**，所有有效判定全 Perfect 时精确达到满分。Hold 尾部和 Slider 节点均纳入总判定数；辅助模式不会获得正式个人最佳。

| 判定 | 头部时间差 |
|---|---|
| Perfect | ±25 ms |
| Great | ±50 ms |
| Good | ±80 ms |
| Bad | ±120 ms |
| Miss | 错过有效窗口或长按/路径跟随失败 |

Bad / Miss 会断连击。完成整张谱面且没有 Bad / Miss 才是 Full Combo；全部 Perfect 才是 All Perfect。空谱面或尚未完成的演奏不会授予这两种完成状态。

结算页提供准确率、最大连击、各判定数量、头部偏差分布、平均偏差与标准差。偏差采用「目标时间 − 输入时间」：正数表示 EARLY，负数表示 LATE。长按尾部、滑动节点和 Miss 不混入头部偏差统计。R 再次演奏，Enter 返回曲库，也可从结算页查看本局回放。

## 设置与校准

设置分六页，Tab 切换分类，Ctrl+S 或「保存设置」保存。调整会实时预览；有未保存内容时，返回或关闭窗口会提示保存、放弃、取消。

- **游玩**：下落速度、鼠标预读时间、背景压暗、轨道不透明度、连击与偏差显示。下落速度只改变阅读距离。
- **声音**：主音量、音乐、音效、打击音色、打击音开关、额外判定提示音和全局音频偏移。
- **操作**：四轨、暂停、重试独立绑定；冲突键位不会被静默接受，Esc 始终可暂停。
- **显示**：全屏、垂直同步、帧率显示、窗口尺寸与帧率上限。启用垂直同步时上限还受显示器刷新率限制。
- **视觉**：樱花/命中粒子、柔光、震动、暗角、特效强度、轨迹、背景柔化。「减少动态效果」停止背景运动、震动和转场动画。
- **数据**：自动保存回放、打开数据目录、成绩导出、存档备份和恢复。

校准前先选择实际使用的音频设备与音量，进入「声音 → 节拍校准」。先听四拍，再跟随**听到的声音**按空格，采集二十个有效样本。动画仅供参考。可重试或保存建议值。正偏移将判定延后；例如经常晚 30 ms，可尝试增加约 30 ms，再实际演奏确认。每首曲目的谱面偏移与全局设备偏移会叠加。

## 导入与制作谱面

在曲库点击「导入谱面」，选择包含 `info.json` 的谱面目录。每张谱面目录包含音乐、元信息及各难度 JSON；图片可选。音乐支持 WAV、MP3、FLAC、OGG Vorbis，封面/背景支持 PNG、JPEG、WebP、BMP。导入会先验证并复制到用户曲库，再刷新列表，错误会在界面提示。

「新建谱面」填写曲名、BPM、难度名和音乐源文件，可附封面与背景。默认输出到用户 `charts` 目录；自选目录必须为空。中文曲名和路径可直接使用。修改内置谱面时，工房会建立用户副本；同 ID 用户副本优先显示。

| 工房操作 | 快捷键/方式 |
|---|---|
| 切换 Tap / Hold / Circle / Slider | 1 / 2 / 3 / 4，或顶部工具按钮 |
| 放置与选中音符 | 在对应键盘时间轴或鼠标编辑区点击；Hold 拖动确定长度 |
| 完成正在绘制的 Slider | Enter |
| 修改属性 | 选中音符后点「属性」；无选中时修改谱面 BPM、偏移、难度名与等级 |
| 播放/暂停音乐 | Space |
| 保存 | Ctrl+S |
| 另存当前难度副本 | Ctrl+Shift+S |
| 撤销/重做 | Ctrl+Z / Ctrl+Y |
| 删除选中音符 | Delete |
| 镜像键盘轨道 | Ctrl+M |
| 完整双区试玩 | F5 从当前时间开始；F6 从选中音符前两秒开始 |
| 原键盘内嵌预览 | F8 |
| 退出试玩 | Esc 返回原编辑器 |

完整试玩会先保存当前修改，使用练习模式，不污染正式记录。编辑期间约每 45 秒写入 `recovery_<难度>.json`；异常退出后可以先复制该文件留底，再在游戏关闭时替换对应难度文件以恢复。离开工房遇到未保存修改时，会弹出保存/放弃/取消。

自定义谱面细节见 [CHART_FORMAT_SPEC.md](CHART_FORMAT_SPEC.md)。

## 数据、备份与升级

默认数据根目录为 `%APPDATA%\Sakura\Sakura\`：

| 目录 | 内容 |
|---|---|
| `config/settings.json` | 设置、曲库偏好、最近回放等 |
| `data/sakura.db` | SQLite 本地成绩、统计、成就 |
| `charts` | 导入或编辑的谱面 |
| `replays` | 演奏输入回放 |
| `backups` | 游戏内生成的独立备份 |
| `logs` | 运行日志 |
| `cache` | 可再生成的打击音等缓存 |

「创建备份」包括数据库快照、设置、回放、自制谱面。恢复时选择这个备份文件夹；游戏先备份现存数据，验证数据库、完成迁移后再替换。恢复失败会回滚并给出提示。恢复不含自制谱面的旧备份时，现有自制谱面保留。

旧计分规则下的成绩保存在迁移后的旧成绩表，新计分重新记录，避免不同规则直接比较。谱面内容变更后，其个人最佳也单独计算。

升级普通版时无需复制程序目录内的存档；便携版则保留整个 `userdata`。高级用户可用 `SAKURA_USER_DIR` 指定数据目录。游戏日志内包含启动与加载错误，遇到问题时可用它定位缺少的文件。
