# Sakura · 樱 玩家指南

## 第一首歌

第一次打开游戏时，建议完成 Tap、Hold、Circle、Slider、综合配合以及「樱枝横梁与组合技」共六课教程。教程随时可以从主菜单重新进入，并自动读取你设置的五键绑定。

打开「开始旅程」，选择曲目与难度，左右方向键切换难度，上下方向键选择曲目，Enter 开始演奏。开局有三秒准备倒计时。

| 音符 / 机制 | 操作 |
|---|---|
| Tap / Hold | 到达左侧判定线时按对应轨道键（默认 A / S / D / F），长按保持至尾部 |
| 樱枝横梁 (Thumb Bar) | 横跨四轨底部的鎏金音符，默认用左手大拇指按 Space 敲击或长按 |
| Circle / Slider | 右侧接近圈收拢时左键点击圆心；滑条按住左键沿路径经过节点 |
| Link 连携 / 樱绽组合技 | 金丝连线需左右同拍击打；带键位徽记的鼠标音符需按住对应键（或右键）点击 |
| 同押横梁 / 跨区同步提示 | 左手多键同押（±6 ms）底部自带鎏金连接横梁与高亮描边；左右手同拍音符（±8 ms）自动显示跨区流光连线与外圈双环提示 |

连续精准命中与组合技会充能顶部 `BLOOM` 槽，满槽自动开启 8 秒 **Sakura Bloom（樱满开）** 状态。音乐与双侧舞台共用抗漂移高精时钟；按 `F3` 可随时开关右上角实时性能与时钟诊断面板。

Esc 暂停，局内 1.5 秒内连按 3 次 `R` 键重新开始当前曲目（顶部 HUD 显示重开确认进度，防止高速演奏误触），F11 切换全屏。切换到其他窗口时自动暂停；继续时重新倒计时，长按中的音符提供短暂恢复容错。

## 曲库、多曲单与练习

游戏内置 **9 首纯原声 OGG Vorbis 官方精选曲库**（《樱落呼吸》《樱光初醒》《繁星》《遥远的星》《樱光未落》《樱落侧链梦》《樱落流光》《一瞬花绽》《Petal Storm: Overdrive》），已全面移除早期程序化合成 WAV 占位曲，覆盖 Lv.2.5～Lv.14.5 多梯度双区协同与舞台演出谱面。搜索框支持曲名、作者、标签，Ctrl+F 聚焦搜索。支持将 `.sakura` 谱面包直接拖入曲库窗口（或在安装版中双击 `.sakura` 文件）一键校验导入。F5 刷新曲库。

除了「♥ 收藏」快捷标记外，选歌界面支持**命名多曲单（Collections）**管理：可在顶栏新建、重命名、删除自定义曲单（如「热身曲单」「右手特训」「高难冲分」），一键将当前选中曲目加入或移出指定曲单，并按曲单过滤曲库；曲单数据保存在本地配置中并支持多设备云端无重复并集同步。

## 幽灵对手同屏竞速与多人对战大厅

- **单人幽灵对手同屏竞速（`GhostRunner`）**：在选歌界面可切换「幽灵竞速：关 / 个人最佳 (PB) / 线上对手」（也可从全球排行榜下载顶尖玩家 `.skr` 回放设为线上竞速目标）。进入演奏后，独立确定性伴跑引擎与当前歌曲时钟实时同步推进：顶部积分区下方呈现双向动态分差条（领先显示鎏金翠绿 `+XXXX`，落后显示绯樱粉 `-XXXX`），右侧鼠标区同步绘制半透明幽灵光标与 220 ms 柔和拖尾轨迹，直观参考顶尖走位且不遮挡本机接近圈。
- **在线多人对战大厅（`SceneArena`）**：从主菜单点击「多人对战」进入 `SceneArena`，支持浏览公开房间列表、输入 6 位房间码秒进房间或创建新房间。房主可在房间内切换对战曲目与难度（自动携带谱面哈希校验），全员点击准备后由房主发起开局同步进入双区舞台；局内左侧紧凑展示房间内玩家实时名次、分数与连击动态卡片，全员完奏后自动生成同场排名并进入赛后多人领奖台。

## 樱华道场段位认定与今日挑战

- **樱华道场 · 段位认定（`SceneCourse`）**：从主菜单点击「樱华道场」进入，挑战官方内置 6 阶段位考核（初段 · 春芽、二段 · 绽樱、四段 · 流岚、六段 · 月影、八段 · 绯闪、皆传 · 樱华绝响），由 3～4 首精选曲目连续演奏组成。段位考核采用**继承制生命槽（`CourseGauge`）**：初始生命 100%，`Perfect` 微幅回血（上限 100%）、`Great` 持平、`Good / Bad / Miss` 按阶位严苛度扣血，单曲过关后按设定比例恢复生命并继承至下一首；生命归零则立即判定考核失败。通关后自动保存段位最高总分、平均准确率与剩余生命，最高通关段位将转化为专属称号徽章（如 `[皆传]`）展示于主菜单在线胶囊与全球排行榜。
- **今日挑战日榜（Daily Challenge）**：每日按 UTC+8 零点日期种子（FNV-1a 确定性轮换）更新当日精选谱面、指定难度与目标分数；断网离线时客户端以完全一致的算法本地生成当日挑战曲目。从主菜单或选歌界面「今日挑战」卡片一键开玩，正式完奏后自动上传成绩并参与当日全球日榜排名。

| 模式 | 用途 | 正式记录 |
|---|---|---|
| 正式演奏 | 原速完成整首曲目 | 保存成绩、统计、成就与回放 |
| 自由练习 | 选择起止区间，0.5–2.0 倍速，可循环 | 不写入正式成绩 |
| 自动演示 | 观察两侧音符与节奏 | 不写入正式成绩 |
| 回放 | 重现已记录的输入 | 不再次增加成绩或游玩次数 |

练习仅计入完整落在区间内的音符判定。默认开启自研 **WSOLA 变速锁定音高**，0.5x–2.0x 变速练习时保持原曲音调不变（也可在设置中切换经典变调）。结算界面按 `Tab` 可展开全屏四象限深度分析报告（含散点误差、UR 值、五轨准度与一键跳转最薄弱段练习）。

「播放最近回放」重现当前曲目与难度的输入记录；回放扩展名为 `.skr`（支持 v1 / v2 格式自动兼容）。

## 成绩与偏差

满分为 **1,000,000**，所有有效判定全 Perfect 时精确达到满分。Hold 尾部和 Slider 节点均纳入总判定数；辅助模式不会获得正式个人最佳。

| 判定 | 头部时间差 |
|---|---|
| Perfect | ±25 ms |
| Great | ±50 ms |
| Good | ±80 ms |
| Bad | ±120 ms |
| Miss | 错过有效窗口或长按/路径跟随失败 |

Bad / Miss 会断连击。完成整张谱面且没有 Bad / Miss 才是 Full Combo；全部 Perfect 才是 All Perfect。空谱面或尚未完成的演奏不会授予这两种完成状态。

结算页提供准确率、最大连击、各判定数量、头部偏差分布、平均偏差与标准差。偏差采用「目标时间 − 输入时间」：正数表示 EARLY，负数表示 LATE。长按尾部、滑动节点和 Miss 不混入头部偏差统计。R 再次演奏，Enter 返回曲库，也可从结算页查看本局回放。

## 设置与校准

设置分六页，Tab 切换分类，Ctrl+S 或「保存设置」保存。调整会实时预览；有未保存内容时，返回或关闭窗口会提示保存、放弃、取消。

- **游玩**：下落速度、鼠标预读时间、背景压暗、轨道不透明度、连击与偏差显示。下落速度只改变阅读距离。
- **声音**：主音量、音乐、音效、打击音色、打击音开关、额外判定提示音和全局音频偏移。
- **操作**：四轨、暂停、重试独立绑定；冲突键位不会被静默接受，Esc 始终可暂停。
- **显示**：全屏、垂直同步、帧率显示、窗口尺寸与帧率上限。启用垂直同步时上限还受显示器刷新率限制。
- **视觉**：主题皮肤热切换预览、舞台双语同步歌词开关、樱花/命中粒子、柔光、震动、暗角、特效强度、轨迹、背景柔化。「减少动态效果」停止背景运动、Chart v4 镜头脉冲缩放（`pulse`）、震动和转场动画。
- **数据**：自动保存回放、多端云存档同步（自动/立即合并最高成绩、最早解锁成就与核心键位流速设置）、GitHub 自动检查更新、打开数据目录、存档备份和恢复。

## 自定义皮肤、打击音包与舞台歌词演出

游戏内置 4 套主题皮肤与专属打击音效包，可在「设置 → 视觉」中实时预览色板、试听打击音并即时热切换：

| 皮肤 ID | 主题名称 | 视觉风格与内置打击音 |
|---|---|---|
| `moonlit_sakura` | 墨樱流光 · Moonlit Ink-Sakura | 经典夜樱粉金琉璃配色 + 清脆晶石打击音（`default`） |
| `neon_cyber` | 霓虹赛博 · Neon Cyber-Pulse | 电光青紫高对比度配色 + 电子合成瞬态打击音（`cyber`） |
| `esports_pure` | 竞技极简 · Esports Pure | 高辨识纯色几何读谱配色 + 干脆木鱼机械轴打击音（`pure`） |
| `ukiyo_jade` | 浮世金翠 · Ukiyo Jade-Gold | 翡翠鎏金和风配色 + 竹韵太鼓打击音（`ukiyo`） |

- **自定义皮肤包（`skin.json`）**：在用户数据目录 `skins/<你的皮肤目录>/skin.json` 新建配置文件即可被自动扫描识别。颜色字段支持 `[r, g, b, a]` 数组或 `#RRGGBB` / `#RRGGBBAA` 十六进制格式，缺省字段会自动回退至墨樱流光默认色板；若皮肤目录下包含 `hitsounds/tap.wav` 等自定义 WAV 文件，将优先覆盖内置合成打击音。
- **Chart v4 舞台演出与双语同步歌词**：支持 Chart v4 的谱面（如《樱光初醒》《一瞬花绽》）会根据乐句重拍与副歌高潮触发舞台脉冲、暗角聚焦、色调流转与漫天樱瓣雨，并在屏幕下方同步渐入渐出呈现中/英/日双语歌词。若希望专注极限读谱，可在「设置 → 视觉」关闭同步歌词或开启「减少动态效果」。

## 在线通行证、全球排行榜与谱面市场

点击主菜单右上角「在线账号」胶囊可一键启用免注册访客通行证，或注册/登录正式账号（默认连接官方在线服 `https://steven-lee.tech:233`，也可自由切换至自建本地服务器）。断网离线时全部本地曲库、练习与工房功能照常运行，正式局成绩会自动缓存并在联网登录后补传。

- **全球排行榜与线上回放**：在选歌界面右侧点击「全球排行」即可查看当前曲目难度的全球最高分榜单与个人名次；点击上榜记录右侧的「回放」可直接下载 `.skr` 输入流并在舞台中重现顶尖玩家操作。
- **在线谱面市场 (`SceneMarket`)**：从主菜单右上角或选歌界面顶部点击「谱面市场」进入。支持关键词检索、最新/热门/高分排序、难度区间滑块过滤、1～5 星评价，以及带实时进度条的「一键下载并安装」（自动核验 SHA-256 并解压至本地 `charts/`，一键跳转开玩）。
- **工房一键发布**：在谱面工房完成编辑并通过谱面合法性校验后，已登录玩家可点击右下角「发布市场」（或将 `.sakura` 包直接拖入谱面市场窗口）直接打包上传更新。

校准前先选择实际使用的音频设备与音量，进入「声音 → 节拍校准」。先听四拍，再跟随**听到的声音**按空格，采集二十个有效样本。动画仅供参考。可重试或保存建议值。正偏移将判定延后；例如经常晚 30 ms，可尝试增加约 30 ms，再实际演奏确认。每首曲目的谱面偏移与全局设备偏移会叠加。

## 导入与制作谱面

在曲库点击「导入谱面」，选择包含 `info.json` 的谱面目录。每张谱面目录包含音乐、元信息及各难度 JSON；图片可选。音乐支持 WAV、MP3、FLAC、OGG Vorbis，封面/背景支持 PNG、JPEG、WebP、BMP。导入会先验证并复制到用户曲库，再刷新列表，错误会在界面提示。

在主菜单点击「谱面工房 / 编辑器」可通过鼠标点击/双击、滚轮或右侧滚动条及方向键选择谱面，切换目标难度胶囊后进入编辑器，也可直接点击「+ 新建空白谱面」。「新建谱面」填写曲名、BPM、难度名和音乐源文件，可附封面与背景。默认输出到用户 `charts` 目录；自选目录必须为空。中文曲名和路径可直接使用。修改内置谱面时，工房会建立用户副本；同 ID 用户副本优先显示。

| 工房操作 | 快捷键/方式 |
|---|---|
| 切换 Tap / Hold / Circle / Slider | 1 / 2 / 3 / 4，或顶部工具按钮 |
| 放置与选中音符 | 在对应键盘时间轴或鼠标编辑区点击；Hold 拖动确定长度 |
| 完成正在绘制的 Slider | Enter |
| 修改属性 | 选中音符后点「属性」；无选中时修改谱面 BPM、偏移、难度名与等级 |
| 播放/暂停音乐 | Space |
| 保存 | Ctrl+S |
| 另存当前难度副本 | Ctrl+Shift+S |
| 撤销/重做 | Ctrl+Z / Ctrl+Y |
| 删除选中音符 | Delete |
| 镜像键盘轨道 | Ctrl+M |
| 完整双区试玩 | F5 从当前时间开始；F6 从选中音符前两秒开始 |
| 原键盘内嵌预览 | F8 |
| 退出试玩 | Esc 返回原编辑器 |

完整试玩会先保存当前修改，使用练习模式，不污染正式记录。编辑期间约每 45 秒写入 `recovery_<难度>.json`；异常退出后可以先复制该文件留底，再在游戏关闭时替换对应难度文件以恢复。离开工房遇到未保存修改时，会弹出保存/放弃/取消。

自定义谱面细节见 [CHART_FORMAT_SPEC.md](CHART_FORMAT_SPEC.md)。

点击主菜单右上角在线胶囊可一键创建访客账号、注册或登录正式账号（默认接入官方在线服 `https://steven-lee.tech:233`，也可在弹窗中切换本地自建 `server/` 地址；断网时自动以离线模式正常运行全部单机内容）。

- **全球排行榜与线上回放**：在选歌界面右侧切换「本地最佳 / 全球排行」即可查看当前曲目难度的全球高分榜与个人排名，点击上榜记录可直接下载 `.skr` 回放进入演奏舞台观看；正式游玩（非练习/演示/辅助模式）结算后会自动异步上传成绩。
- **在线谱面市场（SceneMarket）与工房直传**：从主菜单「谱面市场」或选歌界面顶栏「在线市场」进入，支持关键词搜索、最新/热门/高分排序、最低难度筛选、1~5 星评价，以及带 SHA-256 完整性校验的一键下载安装与游玩。在谱面工房通过谱面合法性校验并登录后，点击顶栏「发布至市场」即可自动打包 `.sakura` 直传更新。

## 数据、备份与升级

默认数据根目录为 `%APPDATA%\Sakura\Sakura\`：

| 目录 | 内容 |
|---|---|
| `config/settings.json` | 设置、曲库偏好、命名多曲单、最近回放等 |
| `data/sakura.db` | SQLite 本地成绩、段位认定记录、统计、成就 |
| `charts` | 导入或编辑的谱面 |
| `skins` | 玩家自定义主题皮肤与 `hitsounds/` 打击音包 |
| `replays` | 演奏输入回放 |
| `backups` | 游戏内生成的独立备份 |
| `logs` | 运行日志 |
| `cache` | 可再生成的打击音等缓存 |

「创建备份」包括数据库快照、设置、回放、自制谱面。恢复时选择这个备份文件夹；游戏先备份现存数据，验证数据库、完成迁移后再替换。恢复失败会回滚并给出提示。恢复不含自制谱面的旧备份时，现有自制谱面保留。

旧计分规则下的成绩保存在迁移后的旧成绩表，新计分重新记录，避免不同规则直接比较。谱面内容变更后，其个人最佳也单独计算。

升级普通版时无需复制程序目录内的存档；便携版则保留整个 `userdata`。高级用户可用 `SAKURA_USER_DIR` 指定数据目录。游戏日志内包含启动与加载错误，遇到问题时可用它定位缺少的文件。
